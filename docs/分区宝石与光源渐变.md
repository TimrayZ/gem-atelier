# 分区宝石与光源渐变

白绿翡翠、紫黄晶和双色碧玺使用随晶体旋转的材料坐标定义颜色分区。紫黄晶与双色碧玺的刻面渲染，按每段内部光路的中点近似混合两组拟合吸收系数；像素与连续通道可分别调整吸收强度。色带、位置和宽度是游戏样本，不是某一颗天然标本的实测数据，也没有模拟完整的偏振与多色性。

翡翠是多晶集合体：游戏采用平底、多面弧顶近似蛋面，并使用考虑内部路径方向的柔和半透外观；这不是完整多晶散射求解。紫黄晶与双色碧玺默认推荐长方阶梯，以展示色区。玩家仍可选择其他切工。

光源切换在约 0.65 秒内平滑混合旧光源与新光源的近似光谱；切换期间再次操作会从当前状态开始过渡。色带和成品几何不会因此改变。

圆形明亮心箭试验型列为四星，代表游戏里的细面和对称操作难度。八心八箭是需专门观察与验证的光学对称图样，并非仅靠面数或命名即可保证；本作没有验证该图样。
